# Watchio Update Changelog

## 0.1.0-dev.2-debug

- Adds Settings -> Check for Updates.
- Checks the public GitHub development update manifest.
- Downloads update APKs inside Watchio with progress.
- Verifies APK SHA-256 before install.
- Uses secure FileProvider handoff to Android package installer.
- Handles Android install-from-unknown-source permission flow.
- Debug-signed pre-release only, not a production build.

## 0.1.0-dev.1-debug

- Native Android Watchio development build.
- Live TV preview and fullscreen playback.
- Movies and Series browsing/playback.
- Global Search, My List, favourites, history, and continue watching.
- XMLTV/EPG cache, TV Guide, and settings foundation.
- Debug-signed pre-release only, not a production build.
